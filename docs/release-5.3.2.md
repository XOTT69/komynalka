# Випуск 5.3.2: вхід в адмінпанель з акаунта

У розділі «Ще → Акаунт і вигляд» власник акаунта `xott69` бачить перехід до адмінпанелі. Рішення про показ приймає Worker після перевірки поточної авторизації, включно з входом через прив’язаний Google-акаунт. Для інших акаунтів, гостя й офлайн-режиму перехід прихований. Пароль адмінпанелі залишається окремим захистом для всіх адміністративних дій.

Запит права доступу повертає лише `allowed`; він не змінює профілі, показники чи тарифи. Конфігурація власника зберігається у `ADMIN_OWNER_LOGIN` в `wrangler.toml`.

Перевірка: тести входу власника, іншого акаунта, неправильного пароля та анонімного запиту; загальна збірка, smoke-тести й сухий запуск Worker. Вхід із реальним паролем власника не автоматизується.
