# 5.17.1 · поля електролічильника

У «Ще → Мій дім» двозонний режим діє для вибраної адреси. У «Показниках» нічні поля доступні тільки після його ввімкнення. Адреси без збереженого вибору типово однозонні. Для старих адрес зі збереженими нічними даними чи зафіксованим двозонним розрахунком збережено сумісність.

Історичні нічні показники, заміни лічильника й суми зберігаються. Нічна чернетка відновлюється після ввімкнення режиму навіть після збереження інших полів цього місяця.

Реліз клієнтський. Worker 5.17.0, чинний KV, ACCOUNT_STORE, Firebase, Push і Telegram використовуються через поточні інтеграції. Резервування — локальна зашифрована копія через [адмінпанель](recovery-operations.md).
