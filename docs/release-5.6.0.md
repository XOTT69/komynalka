# Випуск 5.6.0: власний час нагадувань

Користувач обирає час у «Ще → Нагадування». Значення зберігається в `accountSettings.reminderTime`, синхронізується між пристроями та однаково використовується Web Push і Telegram. Типове значення для наявних акаунтів — 09:00; чинні дні, завершені періоди, адреси, записи й канали не змінюються.

Durable Object планує наступний alarm за часовим поясом `Europe/Kyiv`. Розрахунок враховує літній і зимовий час. Якщо обрана хвилина відсутня в день весняного переходу, нагадування надсилається у першу доступну хвилину після неї. Зміна часу ставить швидку серверну перевірку через чинний механізм синхронізації, але повідомлення не надсилається раніше обраного часу й не дублюється після успішної доставки цього дня.

Екран нагадувань перебудовано у три блоки: час і наступне сповіщення, канали доставки, розклад послуг. Push і Telegram мають окремі картки зі станом, тестом та відключенням; на мобільному вони складаються в одну колонку. Дрібні службові тексти збільшено, а головний розклад виділено без додаткових модальних вікон.

Перед публікацією: створити приватну резервну копію KV і Worker, виконати `npm run check` та `npm run worker:check`, перевірити 390 px і desktop, розгорнути сумісний Worker перед frontend. Формат акаунта не мігрує; відкат frontend не потребує відновлення даних.
