# Перевірка швидкості на фізичних телефонах

Це протокол майбутнього вимірювання, а не підтвердження вже виконаного тесту. Лабораторний Chromium на Mac не відтворює iPhone Safari або встановлену PWA. Власні історії, логи входу, паролі та тексти звернень для вимірювання не збираємо.

## Пристрої й умови

Записати модель, версію ОС/браузера, спосіб запуску (Safari / PWA, Chrome / PWA), версію Комуналки, Wi-Fi або мобільну мережу, стан кешу. Використати окремий тестовий акаунт із вигаданими 200, а потім 1000 записами; не створювати такі історії в особистому акаунті. Перед тестом вимкнути режим енергозбереження та дати пристрою охолонути. Мінімум: один фізичний iPhone і один Android середнього класу.

## Сценарії

| Перевірка | Що вимірюємо / підтверджуємо |
| --- | --- |
| 5 перших запусків | Від відкриття до Огляду з адресою й даними; окремо свіжий кеш і вже встановлена PWA |
| 5 відкриттів історії | Від натискання до видимих карток; прокрутка, пошук і «Показати наступні 48» |
| Внесення показника | Відклик клавіатури, розрахунок, збереження; число й чернетка зберігаються після повторного відкриття |
| Офлайн | Запуск із локальною копією, зміна чернетки, відновлення мережі й синхронізація без втрати |
| Google-вхід | Safari і встановлена iPhone PWA; успішне повернення в акаунт |
| Оновлення PWA | Кнопка лише для іншої збірки; збережені дані й чернетки після оновлення |
| Нагадування | Вибраний час за Києвом; окремо відповідь сервісу, фактичний показ на телефоні та перехід у потрібну адресу |

Звітувати медіану й максимум 5 запусків, а не один найкращий результат. Орієнтир для пошуку проблем: Огляд до 3 с у стабільній мережі, перемикання вкладки до 500 мс, без тривалого зависання під час введення. Це цілі перевірки, а не поточні гарантії.

Зберегти лише модель/версію, умови, час і результат сценарію. Якщо потрібен запис екрана, використати виключно вигадані дані. Реальний INP/LCP для користувачів потребує окремого прозорого збору й оцінки згоди; автоматичне завантаження браузерних логів тут не ввімкнено.

## Лабораторія, яку вже можна повторити

`npm run measure:performance` запускає тільки localhost, блокує зовнішню мережу браузера і використовує вигадані акаунти. Chromium: 390×844, CPU ×4, 70 мс затримки, 10/5 Мбіт/с, свіжий контекст без HTTP-кешу. Звіт `test-results/browser-performance.json` містить усі 5 повторів для 200/1000 записів. Першу сторінку історії обмежено; статистика має враховувати всі записи.

Час готовності вимірюється до видимого Огляду з адресою та прибраним splash. Час відкриття історії включає виконання тестової дії й два кадри після появи вкладки. Це показники локальної лабораторії, не production latency і не Core Web Vitals. Перший baseline: `docs/performance-baseline-5.16.0.json`; перед порівнянням повторити обидві збірки на тій самій машині й за однакових умов.
