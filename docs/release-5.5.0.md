# Випуск 5.5.0: найближча дія та прозорі нагадування

На головній сторінці дія визначається зі збережених показників, налаштованого періоду передачі, наявності готового листа та неоплаченої суми. Якщо час передати воду і для поточного місяця є лист, основна кнопка відкриває готову чернетку. Відкриття пошти саме по собі **не** позначає показники переданими: користувач підтверджує це після фактичного надсилання.

У «Ще → Нагадування» видно наступний день о 09:00 за Києвом, послугу і реально підключені канали. Для підключеного пристрою або приватного Telegram-чату є окрема кнопка тесту. Тест надсилається тільки після перевірки акаунта й належності endpoint/чату; повторний запуск обмежено до одного за хвилину. Відповідь push-сервера означає прийняття повідомлення, а не гарантований показ на пристрої. Дата останнього успішного нагадування не підміняється тестовою. Історія, тарифи та записи від тесту не змінюються.

На сторінці знайомства прибрано непідтверджені оцінки й кількість користувачів, виправлено приклад суми. Тексти дрібних станів і дії на вузькому екрані стали читабельнішими.

Формат акаунта й KV не мігрує. Worker розширює лише вже наявний Durable Object метаданими тестової доставки, не стираючи інших полів. Перед Worker-деплоєм створити приватну копію KV і коду Worker; якщо доступний адміністраторський експорт, зберегти також авторитетні акаунти Durable Object. Перевірити `npm run check`, `npm run worker:check`, мобільне демо й стан production після розгортання. Порядок: сумісний Worker, потім статичний frontend. Відкат frontend не вимагає перезапису акаунтів.
