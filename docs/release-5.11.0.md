# Випуск 5.11.0: допомога до входу

- На екрані входу з’явилася кнопка «Не можете увійти? Повідомити про проблему».
- Форму можна надіслати без акаунта, якщо не працює логін, реєстрація або Google-вхід.
- Email для відповіді необов’язковий; показники, платежі й дані акаунта не передаються.
- Звернення потрапляє у звичайну чергу адмінпанелі з позначкою «До входу» та категорією проблеми.
- Публічна форма має приховане антибот-поле, серверну перевірку та ліміт три повідомлення на IP за добу.
- IP використовується лише у вигляді короткого хешу для ліміту та не записується у звернення.
- Обраний тариф міста або постачальника тепер залишається видимим у списку та зберігається окремо для кожної адреси.
- Перемикачі «Двозонний» і «Зимовий» мають контрастний активний стан, позначку та підписи «Увімкнено / Вимкнено».
