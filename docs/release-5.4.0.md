# Випуск 5.4.0: пошта й Telegram

Готовий лист можна відкрити через системну пошту (`mailto:`; на iPhone це вибраний за замовчуванням застосунок), у Gmail у браузері або не відкривати й скопіювати. Адресат, тема та текст заповнюються зі збережених показників. Редактор постачальника поділено на основні дані, контакти й необов’язковий шаблон. Кнопки копіювання та сам діалог підтверджують успішне копіювання. Вибір пошти зберігається лише на цьому пристрої; історія, картки, нагадування й оплати не мігрують.

Telegram — окремий канал на додаток до Web Push. Він використовує наявний серверний секрет `TG_BOT_TOKEN`, одноразове посилання на приватний чат (10 хвилин), Telegram webhook із `secret_token`, авторизований стан прив’язки в Durable Object акаунта та `/stop` чи кнопку відписки. Повідомлення надходять за чинним календарем о 09:00 Europe/Kyiv, щонайбільше раз на день. Враховуються вимкнені послуги та «Вже передав». Бот не отримує показники чи пароль. Чат не прив’язується до двох акаунтів одночасно.

Для користувача: «Ще → Нагадування», увімкнути нагадування, натиснути «Підключити Telegram», відкрити посилання та натиснути **Start** у боті. Повернутися в застосунок: стан підключення оновиться. Бот також приймає `/stop`. Пуш на телефоні налаштовується незалежно.

Для адміністратора: створити окремого бота через BotFather і встановити токен як Cloudflare Worker secret `TG_BOT_TOKEN`, не додаючи його до Git або frontend. Під час першого підключення Worker перевіряє чинний webhook і встановлює власний `/telegram`. Якщо бот уже підключений до іншого webhook, звичайні акаунти отримують помилку; лише авторизований власник `ADMIN_OWNER_LOGIN` може перенаправити його після явного погодження. Токен не показується клієнтові. Після випуску перевірити підключення на власному акаунті та доставку в активний день. Не надсилати масових тестових повідомлень.

Hotfix 2026-09-22: Cloudflare Worker з наявною compatibility date не приймає `fetch` із `redirect: "error"`. Через це запити до Telegram API та Web Push не доходили до мережі. Використовується `redirect: "manual"` і окрема заборона переходів; тайм-аут реалізовано через `AbortController`. Чинний токен підтверджено для `@KomunProgaBot`. Тимчасовий публічний діагностичний endpoint видалено.

Перед розгортанням зробити нову приватну резервну копію KV та авторитетних акаунтів. Перевірки: `npm run check`, `npm run worker:check`; окремі тести перевіряють автентифікацію, webhook, однократну прив’язку, відписку, графік доставки, незмінність показників та заповнення Gmail і `mailto:`.
