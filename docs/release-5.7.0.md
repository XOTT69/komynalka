# Випуск 5.7.0: комфортний дизайн і коротший щомісячний шлях

## Результат

- Світла тема отримала м’яку синьо-лавандову палітру, теплі поверхні, спокійні тіні й окремі ненав’язливі акценти послуг.
- Темна тема використовує приглушені сині поверхні без різкого контрасту.
- Головний фінансовий підсумок став виразним, а решта карток — спокійнішими й візуально узгодженими.
- У списку справ є прогрес місяця та зрозумілий стан завершення.
- Після фактичного надсилання готового листа користувач може позначити його надісланим; дата зберігається окремо для адреси, послуги й місяця.
- Підтвердження листа автоматично завершує відповідний крок передачі, не змінюючи показники чи історичні нарахування.
- Активне нагадування можна відкласти до завтра окремо для поточної адреси.
- Push-повідомлення відкриває одразу внесення показників або центр нагадувань.
- Додано PWA shortcuts для оплати й нагадувань.
- Адмінпанель отримала узгоджену палітру й живий стан API, KV та протоколу синхронізації.
- Версія повної резервної копії адмінпанелі тепер відповідає версії production-збірки.

## Сумісність даних

Нові поля лише доповнюють `accountSettings`:

- `providerDeliveries[address][service][month].sentAt`;
- `reminderSnoozes[address]`.

Адреси, записи, тарифи, часткові оплати, чернетки, нагадування та невідомі поля старих акаунтів не переписуються і не видаляються. Старі клієнти можуть ігнорувати нові поля без втрати даних.

## Перевірка перед випуском

1. `npm run check`.
2. `npm run worker:check`.
3. Повна резервна копія Worker і KV та повторна перевірка кожного значення.
4. Ручний перегляд світлої й темної теми на мобільному та широкому екрані.
5. Публікація Worker перед клієнтом.
6. Перевірка версії HTML, нового Service Worker і health endpoint.
